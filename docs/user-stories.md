# Hospital Management System - User Stories

## 1. Introduction

This document describes the major user stories for the Hospital Management System.

User stories capture the gaols and needs of different users and help guide system design and implementation.

The system supports five primary user roles:

* Patient
* Receptionist
* Doctor
* Lab Technician
* Administrator

---

## 2. Patient User Stories

US-PAT-01
As a patient, I want to register my personal information so that I can receive medical services.

US-PAT-02
As a patient, I want to view my appointment details so that I know when to visit the hospital.

US-PAT-03
As a patient, I want to view my visit history so that I can track my medical records.

US-PAT-04
As a patient, I want to view my laboratory test results so that I can understand my health condition.

US-PAT-05
As a patient, I want to view my bills and payment status so that I know my financial obligations.

---

## 3. Receptionist User Stories

US-REC-01
As a receptionist, I want to register new patients so that patient information can be stored in the system.

US-REC-02
As a receptionist, I want to search for existing patients so that I can quickly access their information.

US-REC-03
As a receptionist, I want to update patient information so that patient records remain accurate.

US-REC-04
As a receptionist, I want to schedule appointments so that patients can meet doctors at appropriate times.

US-REC-05
As a receptionist, I want to cancel or reschedule appointments so that scheduling conflicts can be resolved.

US-REC-06
As a receptionist, I want to create walk-in visits so that patients without appointments can receive care.

US-REC-07
As a receptionist, I want to create emergency visits so that urgent cases can be processed immediately.

US-REC-08
As a receptionist, I want to generate bills so that patients can be charged for services.

US-REC-09
As a receptionist, I want to process payments so that bills can be marked as paid.

---

## 4. Doctor User Stories

US-DOC-01
As a doctor, I want to view my assigned appointments so that I know which patients I will see.

US-DOC-02
As a doctor, I want to access patient medical histories so that I can make informed decisions.

US-DOC-03
As a doctor, I want to create diagnosis records so that patient conditions can be codumented.

US-DOC-04
As a doctor, I want to add prescriptions so that patients receive proper treatment.

US-DOC-05
As a doctor, I want to request laboratory tests so that additional medical information can be collected.

US-DOC-06
As a doctor, I want to update medical records so that patient information remains current.

---

## 5. Lab Technician User Stories

US-LAB-01
As a lab technician, I want to view pending laboratory test requests so that I can perform required tests.

US-LAB-02
As a lab technician, I want to update laboratory test statuses so that doctors can track test progress.

US-LAB-03
As a lab technician, I want to enter laboratory test results so that doctors can review them.

---

## 6. Administrator User Stories

US-ADM-01
As an administrator, I want to manage staff information so that hospital personnel records remain accurate.

US-ADM-02
As an administrator, I want to manage department information so that staff can be assigned correctly.

US-ADM-03
As an administrator, I want to view system reports so that I can monitor hospital operations.

US-ADM-04
As an administrator, I want to maintain system data so that the system remains reliable.

---

## 7. Cross-Functional User Stories

US-SYS-01
As a system user, I want all data to be saved automatically so that information is not lost when the program closes.

US-SYS-02
As a system user, I want the system to validate my input so that incorrect data cannot be entered.

US-SYS-03
As a system user, I want clear error messages so that I can correct mistakes easily.

US-SYS-04
As a system user, I want the system to load existing data when it starts so that I can continue previous work.

---

## 8. Core Workflow Summary

The Hospital Management System supports the following core workflows:

1. Patient Registration
2. Appointment Scheduling
3. Patient Visit Management
4. Medical Record Creation
5. Laboratory Test Management
6. Billing and Payment Processing
7. Data Persistence and Reporting
